# 知识交接、地图与协作维护

## 按任务提取，不复制完整历史

主调度者先恢复完整当前快照，再按当前目标选择相关地图条目、子地图和图纸。只传必要事实、完整适用约束和可访问来源；不把全部记忆、源码、长日志和无关历史附给每个角色。

知识摘录可在会话中表达，标识为 knowledge-extract-v1，提供：

```text
source: 当前快照与相关地图/图纸路径、章节/符号、内容基准
scope: 本任务覆盖的模块、直接依赖、未读与未知区域
constraints: 本任务全部适用用户要求、数据/权限边界及来源
facts: 已核验事实、核验候选/日期；假设与建议分开
routes: 精确源码入口、关键符号、契约和验证入口
drawings: 相关源路径/修订/对象 ID、逐项现状或目标与确认/验证状态、适用契约版本
freshness: 相关 commit 与 staged/unstaged/untracked 覆盖、变化或待复核项
gaps: 仍需代码、环境、候选、原始证据或授权的具体缺口
```

主调度者将摘录与本次需求、验收、候选、工作目录、写入范围、资源和产物位置合并为可开工任务包。源码默认以主仓库主 checkout 为共同工作位置；并行 Agent 按互不重叠的文件范围写入，共享文件指定唯一 owner。跨仓库工作确需额外 worktree 时只设一个共享 worktree，位于主仓库根目录下可见位置，不放在 `.agent-workspace/`。采用 multi-agent-engineering 时由其 task-handoff-v1 负责派工与通信；不用该 Skill 时也可直接以这些字段交接，不要求安装另一个 Skill。

接收者优先从入口定位源码，必要时读取直接依赖；地图不替代编辑前读实际文件，也不约束必要只读调查的路径数量。没有地图时，对当前问题做有界调查并回报可复用入口；不把地图齐全、全仓扫描或额外审批设为每个任务的前置条件。

测试执行仍需稳定候选、环境与断言；交互验证需真实页面和允许动作；审查需原始需求、候选差异与相关原始证据；顾问需难题、源码与失败依据；记忆维护需完整当前快照和待改文件；cleaner 需清单、引用占用、保留与授权。材料不足明确 gap，先补必要缺口，其他独立授权工作继续。

规划阶段可向 interactive-planning-doc 提供有来源的现状摘录、代码入口与图纸，减少重复调查；缺口仍须核验。主计划管理需求与目标方案，按原维护协议接收有效决定和事实后，current.md 保留恢复必需的目标、约束、实际状态与主计划路径/有效修订，不复制全计划或任务表，不把 AI 技术选择、目标或计划中的验证记作已实现/已验证。

## 地图与图纸

下表路径均相对于 `.agent-workspace/memory/`；源码和正式产品文档仍沿用工程原位置。

| 材料 | 用途 |
| --- | --- |
| references/code-map.md | 总定位：模块职责、入口/符号、直接关联、验证入口、子地图和未知范围 |
| references/architecture.md | 经证据核验的现状说明：边界、依赖、数据流与关键不变量；采用标准 JSON 时引用实际源路径/修订/对象 ID，不复制契约表 |
| references/maps/<scope-id>.md | 按需领域子地图：局部调用/事件链、状态/数据所有权、直接边界和测试定位 |
| references/drawings/<topic-id>.md | 按需独立专题：生命周期、失败恢复、并发或界面状态等较长细节 |

小项目可只有简短总地图。反复调查、关系复杂、可独立分工或总地图细节影响定位时再拆子地图，通常先总图和一层子图；不按源码每个文件夹自动造图，不构建深层必读索引链。current.md 保留恢复必需的架构概览与有效结论，不变成地图目录。

每份材料注明范围、来源路径/符号、基准 commit 与相关未提交变化、核验日期、证据位置、未知关系和复核触发点。路径存在不代表语义仍成立；触及接口、状态、配置、依赖或直接调用方时定点复核，未受影响事实保留原日期。动态关系无证据就标未知，不用自动目录/符号扫描冒充真实运行图。

原始代码或当前维护中的正式材料已有准确描述时引用它，不造同内容影子副本。采用 architecture-design 时，同一范围跨任务共用一份标准 JSON 机器源，现状、目标、决定与实现/验证情况逐项记录；新建的稳定源按需放 `.agent-workspace/architecture/`，已有有效源原位复用，不复制到新任务或记忆目录。现状说明引用实际源路径、修订和对象 ID，HTML 只是派生快照，不另维护 Mermaid 或手工契约表作为第二真源。未采用该技能时保留既有可编辑文本/图纸，不强制安装或格式转换；同一契约仍只有一个维护位置。

以上 JSON 与现状说明的分工以 JSON 已确认为该范围唯一详细源为前提。既有 `architecture.md` 若仍是正式权威，先保留内容并协调唯一权威与获准转换范围，不自行降级或删去契约；转换未完成时继续依据有效旧源分析，明确标准 JSON 渲染尚不可用，不能复制一个默认源冒充完成。

采用 architecture-design 时，任务实例结果只保存建议、差异和报告，引用共享 JSON 的修订与对象，不另立目标设计源。架构师/设计师负责技术内容，由获准的唯一源 writer 更新对应对象；实现者报告落地差异，执行者提供证据，再由记忆 writer 更新现状说明与引用，不能把建议直接记为已实现。迁移或覆盖既有源须明确授权，检查引用和恢复依据，不因记忆归并自动取得图纸写入权。未采用该技能时目标设计可按原任务结果协议保存，仍标明草案、已采纳、已实现、已验证及来源；未实现或未验部分保持计划/待验身份。

## 事实批次与唯一 writer

1. 各角色回报任务/输入版本、实际候选、事实/假设/建议、来源与验证、应复核地图和未完成项。主调度者接收并确定本批采用的事实与有效决定；角色互通消息不能自动创造全局决定。
2. 明确批次标识、受管文件、当前校验值、采用报告与证据、有效约束、冲突和允许动作，分配唯一记忆 writer。其他角色及主调度者在该写入范围交回前不并发编辑。
3. writer 完整读当前快照和待改文件，定点核对必要证据。报告与源码/原始结果冲突、候选变化、用户决定变更或旧消息到达时，不自动采纳过期内容；向协调者报告具体影响，重建本批输入或保留待核实。
4. 严格执行维护参考的原样归档、并发检查、替换与回读。维护已授权且输入就绪即可执行，不要求用户逐次批准；未获维护权限仅给草稿。无实质内容变化不重写、不新增归档。
5. 返回批次、实际纳入报告/决定、文件旧/新校验值、归档位置、内容与路径核验、隐私检查、未纳入项和原因、交回写入权。主调度者核对语义变化与回执后接收，避免逐行重写同一文件。

新的事实进入后续批次；影响本批正确性的新决定应及时通知并调整或中止本批。不要把用户的新要求排队后仍写出自称最新的旧状态。错误测试必须保留；旧候选通过可以保存原身份，但不能表述为新候选通过。

采用 development-pipeline 时，接收项目/运行身份、有来源的 REQ、里程碑/切片、当前顺序轮次/attempt、实际候选、检查点与审查处置。current.md 直接总结有效状态、关键结果、阻塞、下一步及运行目录/最终 report.html 入口；详细机器进度引用事件源与可重建静态观察器，不人工镜像每条事件。各项目/运行的视图独立，completed 停止轮询，不代表其他任务进程已终止。JOB 完成、检查点通过、整轮接受与实际交付分别保留身份；恢复时核对事件投影与实际资源，不把上报状态当进程探测。未采用流水线时原维护协议不变。

流水线失败期间已在途任务的终态也属于待接收事实，不能因为新增工作暂停而丢弃。保留原 attempt、候选、结果与证据；兄弟任务成功不代表整轮通过，新增失败不覆盖既有顾问/阻塞决定。回流后的当前快照直接说明新尝试与仍有效结论，旧尝试完整结果继续引用事件与证据，不伪装为当前通过。

## 长期证据与工作区清理的交接

任务实例 evidence/ 是现场材料，scratch/ 是临时中间产物。长期结论引用的必要证据按批准范围固化到 .agent-workspace/memory/evidence/<evidence-id>/，或继续引用已有稳定保留位置。只选必要内容，不为归档复制全部工作区或秘密。

核对源产物已稳定、身份和候选明确，检查隐私，保存必要原始内容与来源映射，验证内容和路径，再更新当前快照/参考的引用。manifest 说明原任务/实例、来源路径、环境/候选、保存清单和必要校验值。证据不覆盖旧版本，搬运不等于重新验收。

活跃架构 JSON、`memory/references/architecture.md` 和仍被引用的图纸依据不属于普通临时清理，即使权威源仍在某个旧任务目录也不能随任务结束删除。先核对当前快照、任务交接、历史证据与网页快照对实际源路径/修订的引用；迁移或覆盖须获准并验证内容、引用和恢复。仅派生 HTML 在确认可从保留源重建、没有必须保留的引用且清理已获授权时才可清理；可重建不等于自动获准删除。

实例结果成功交接并由主调度者接收后，先按运行时能力回收该 Agent，确认其及后台进程不再占用材料；再在稳定证据、记忆引用和恢复核验完成后，将来源列为 cleaner 的清理候选。回收无法确认时保留并报告；清理仍须精确范围与删除授权。仍被旧快照、不可变报告或其他任务引用时保留原路径可达性或可核验恢复办法。归档、固化或并发检查失败时保留源材料并报告缺口。Cleaner 无权按“过期”自行删除记忆 archive/、地图或长期证据。

## 任务检查点

原线程继续同任务只补增量；新 Agent 接替需任务候选/目录、相关路径与契约、已确认事实、排除依据、待证项、具体停止点/下一步、dirty 文件、未完成工具/进程与资源状态。检查点按任务实例保存，current.md 只归并当前有效结论与入口。恢复时核对真实运行状态，旧 Agent ID 不证明仍在执行；文件持久化不保证全部未记录上下文无损保留。
