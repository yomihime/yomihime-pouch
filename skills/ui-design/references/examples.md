# 按场景选择的例子

以下为思考与核验示例，不是固定样式，也不授权更改。

- **提取 Qt 桌面界面**：对照设置页和主要工作区，记录 `QPalette`、样式表、系统字体及共享控件的实际来源；比较亮暗主题与禁用状态。若一个页面用不同圆角，先标注差异，不立刻统一。
- **密集后台表格**：定位用户最常扫描的几列，维持表头与数值对齐，为长内容提供可发现的完整查看方式；核对排序、批量选择、空结果和窄窗口横向溢出。
- **表单修复**：错误信息紧邻对应字段并保留用户输入，提供可执行的修正提示；检查键盘焦点和屏幕阅读器名称。仅修复目标表单，不顺手改全站颜色。
- **中日文设置页**：用真实许可的测试文案检查中日字形、标点、拉丁数字、长按钮文本和放大后的换行；若日文较长，优先让布局适应而非删掉关键含义。
- **深色主题**：在实际主题下检查文本、边框、焦点和禁用态的可辨性，状态再加文字或图标；同时验证亮色主题没有回归。
- **从零创建工具**：先设计主要任务、空态和失败恢复，再选择少量可复用间距、颜色及组件；色彩可大胆或低调，以任务、品牌、对比与用户偏好决定，不预设禁用某个色系。
