# 官方参考目录

以下只是链接，不是打包的素材或依赖。按问题有选择地查阅，不需要全部获取。项目已有组件和离线资料优先；每次用户请求最多获取一个资源库，记录所用来源 URL、版本或访问日期、许可证及适用范围，核对许可证是否覆盖预期用途，保留项目要求的归属声明。不要自动运行下载的代码或脚本；需要新增依赖时先遵守项目约定及用户授权。

- [Qt Widgets](https://doc.qt.io/qt-6/qtwidgets-index.html) 和 [Qt Style Sheets](https://doc.qt.io/qt-6/stylesheet.html)：桌面控件、平台行为与样式。
- [WAI-ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/)：Web 控件模式、语义与键盘交互；按实际平台适用性使用。
- [Radix Primitives](https://www.radix-ui.com/primitives/docs/overview/introduction)：Web 可访问组件原语的参考。
- [shadcn/ui](https://ui.shadcn.com/docs)：可组合的 Web 组件实现参考；复制代码前核对实际版本和许可。
- [Lucide](https://lucide.dev/)：图标目录和用法；核对项目所用资源与许可。
- [Material Design](https://m3.material.io/)：组件、布局、主题和可访问性参考，不要求套用其外观。
- [Noto Fonts](https://fonts.google.com/noto)：字体与语言覆盖参考；使用前检查具体字体文件许可和平台回退。

离线或来源不可访问时，继续使用项目已有资源并标记无法核实的内容；不要虚构版本或许可证。

## 许可核对入口

以下链接仅为核对起点，不能替代对实际版本、文件和用途的审查；软件许可证不一定适用于文档、示例或素材。

- Qt 的模块、绑定及商业版本条款各异，参见 [Qt 开源许可义务](https://www.qt.io/development/open-source-lgpl-obligations/)。
- W3C 的 ARIA 指南及示例代码可能适用不同条款：见 [WAI 材料使用条款](https://www.w3.org/WAI/about/using-wai-material/) 和 [APG 示例代码说明](https://github.com/w3c/aria-practices/wiki/Code-Guide)。示例是教学材料，不能默认可直接用于生产。
- [Radix Primitives 许可证](https://github.com/radix-ui/primitives/blob/main/LICENSE)；[shadcn/ui 许可证](https://github.com/shadcn-ui/ui/blob/main/LICENSE.md)。shadcn 第三方 registry 文件可能有独立许可和来源，应逐项审查。
- [Lucide 许可证](https://github.com/lucide-icons/lucide/blob/main/LICENSE)包含对源自 Feather 图标的额外声明，分发时按适用条款保留完整通知。
- Material 设计文档与具体素材许可可能不同；[Material Design Icons 仓库](https://github.com/google/material-design-icons)列有图标许可证。不要将图标许可推及全部文档或素材。
- [Noto Fonts 许可证](https://github.com/googlefonts/noto-fonts/blob/main/LICENSE)；具体字体文件和发行版本也须核对。
